# 8PSS — Personal Secret System

Public concept site for **8PSS — Personal Secret System**.

8PSS explores a private identity model in which encrypted credentials belong to identities, rather than identities being reduced to passwords.

## GitHub Pages

This repository is published from the `main` branch root. The canonical custom domain is declared in `CNAME` as `8pss.org`.

## DNS for 8pss.org

Configure the apex domain with GitHub Pages' four `A` records and four `AAAA` records, and configure `www` as a `CNAME` to `gitexfreq.github.io`. Preserve unrelated mail, verification, and service records.
